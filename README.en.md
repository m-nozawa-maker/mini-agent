# Mini Agent

A sample project for learning and implementing agent behavior.

## Main Technologies Used

- TypeScript
- Jest (Testing Framework) - Currently just included
- Vercel AI SDK (OpenRouter Integration)

## Environment Variables Setup

Create a `.env` file and set the following environment variables:

```
OPENROUTER_API_KEY=your_api_key_here # OpenRouter API Key
TEMP_DIR=./temp # Directory where file operations are allowed
```

## Development Environment Setup

Installation

```bash
npm install
```

Start

```bash
npm start
```
